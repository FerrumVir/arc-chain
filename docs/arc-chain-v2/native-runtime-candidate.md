# Native runtime candidate (private protocol 4)

The candidate accepts signed `NativeInferenceRequest`, `NativeInferenceFinalize`, and `NativeInferenceRefund` transactions only after a fresh, rooted private activation. All other transaction ingress is unavailable while that activation is present. `GET /native-inference/context` exposes the frozen binding; `GET /native-inference/receipt/{request_id}` exposes observed canonical receipt status and verified transaction/block links. The receipt explicitly does not assert consensus finality.

The worker reads only StateDB's bounded pending index. Its decision store is validator/genesis/context/request scoped, bounded on read, durable before emission, and reloads the exact verified vote after restart. The finalizer accepts only frozen-member signatures over the same request/output, requires strictly more than two-thirds stake, serializes its outer nonce, and submits the resulting signed finalize transaction through normal mempool admission.

`CanonicalI8NativeExecutor` is available as a private adapter, but node startup does not construct it. Its public constructor hashes the supplied GGUF source before loading the corrected interleaved-RoPE canonical-I8 profile, requires exact versioned profile and generation commitments, an explicit reference-qualification flag, and pre-qualified LE-u32 input tokens. It does not call the legacy text tokenizer. Broader tokenizer and model-quality qualification remain required before production execution is enabled.

Focused validation currently covers six local validator keys on one persistent StateDB with a synthetic executor: signed mempool request admission, five-of-six certificate construction, signed finalization, receipt links, WAL reopen, expiry refund, and replay rejection. It does **not** prove six independent replica StateDBs, P2P transport, distributed model inference, consensus finality, or live gateway execution. `cargo test -p arc-node native_inference --lib` runs 6 focused worker tests; the RPC activation/receipt branch is covered by `rpc::tests::native_rpc_requires_private_activation_and_returns_observed_receipt_links`.
